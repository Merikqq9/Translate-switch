# Технический план Switch Translator RU

## Целевая конфигурация
- Консоль: Nintendo Switch Lite.
- CFW: Atmosphère.
- Overlay loader: nx-ovlloader + Tesla Menu.
- ПК: Windows 10.
- Источник: японский игровой текст.
- Результат: русский текст в том же месте экрана.

## Пользовательский сценарий
Пользователь один раз устанавливает единый комплект проекта на SD-карту и Windows 10. После запуска игры система автоматически получает кадры, обнаруживает новые реплики, переводит их и выводит русский текст в координатах исходной реплики. На экране нет отдельного окна, панели управления, статистики или истории.

## Важное различие: наложение и замена
Tesla overlay умеет рисовать поверх игрового изображения, но рисование русского текста поверх японского не удаляет оригинальные пиксели. Чтобы получить эффект замены, нужно определить прямоугольник исходной реплики, закрыть исходную надпись подходящей маской, по возможности восстановить фон внутри маски и нарисовать русский текст в том же прямоугольнике. На однородном фоне достаточно маски. На сложном фоне может потребоваться inpainting; идеальное восстановление не гарантируется. Если восстановить фон нельзя, исходные символы могут частично просвечивать.

## Предлагаемый конвейер
1. Захват кадра на Switch: исследовать совместимый с Atmosphère способ получать игровые кадры непрерывно или с разумной частотой. Не предполагать, что обычный Tesla overlay сам имеет доступ к framebuffer игры.
2. Передача кадра на Windows 10: использовать локальное USB/Wi-Fi соединение с минимальной задержкой.
3. Обнаружение и OCR: на ПК определять области японского текста, распознавать символы и координаты.
4. Перевод: переводить только новые/изменившиеся реплики, кэшировать результат.
5. Возврат результата: передавать на Switch русский текст, прямоугольник, стиль и маску/фоновые данные, необходимые для отрисовки.
6. Отрисовка: Tesla overlay отображает русский текст в исходном месте. Интерфейс не содержит ничего, кроме самого перевода.

## Единый проект и установка
Репозиторий и релиз остаются едиными. Внутри одного исходного проекта могут быть технические модули для Switch и Windows — это не отдельные пользовательские приложения. Цель релиза: один архив установки с файлами Switch и Windows-компонентом, единая конфигурация и короткая инструкция.

## Прототипы и критерии готовности
### Этап 1 — доказать захват
- Получить кадр игры на Switch Lite.
- Передать его на Windows 10.
- Проверить задержку и совместимость с несколькими играми.
- Убедиться, что система не ломает работу игры.

### Этап 2 — OCR и перевод
- Распознать японский текст и его координаты.
- Перевести тестовые реплики на русский.
- Не отправлять повторно неизменившийся текст.

### Этап 3 — точное размещение
- Нарисовать русский текст по координатам OCR.
- Проверить маскирование исходных символов.
- Измерить читаемость, мерцание и задержку.

### Этап 4 — единый релиз
- Собрать overlay, Switch-side capture component и Windows-side processing в одном release archive.
- Добавить установку/удаление и проверку подключения.
- Проверить на реальной Switch Lite.

## Технические ориентиры
- switch-ocr демонстрирует связку Atmosphère screenshot capture, OCR на хосте и Tesla HUD.
- switch-frame-tap демонстрирует более общий захват/передачу игровых кадров на Windows и другие платформы.
- libtesla — стандартная библиотека для реализации Tesla overlay.

Это ориентиры для изучения, а не уже подключённые зависимости проекта. До проверки исходников и теста на консоли нельзя обещать непрерывный захват, низкую задержку или универсальную работу во всех играх.
