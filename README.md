# Switch Translator RU

Минималистичный автоматический переводчик японского текста в русскоязычных играх для Nintendo Switch Lite (Atmosphère + Tesla).

## Цель

Показывать русский перевод непосредственно в области исходного японского текста, без отдельного окна перевода и без лишних элементов интерфейса.

## Требования к первой версии

- Автоматически обнаруживать игровые реплики на японском.
- Распознавать японский текст (OCR).
- Переводить его на русский.
- Отображать перевод в координатах исходной реплики.
- Не показывать меню, статистику, историю или дополнительные панели.
- Не закрывать важные элементы игрового интерфейса.

## Важное техническое ограничение

Обычный Tesla overlay может рисовать поверх изображения игры, но сам по себе не может универсально удалить уже отрисованные игрой японские символы. Для настоящей замены текста потребуется получить кадр/область экрана, распознать и локализовать текст, восстановить фон под оригинальной надписью и нарисовать русский текст. Возможность захвата игрового изображения зависит от доступных системных интерфейсов Atmosphère и должна быть проверена на реальной Switch Lite.

## Архитектура проекта

Репозиторий будет единым проектом и единым исходным деревом. Внутри могут находиться компоненты для разных целевых сред (Switch и, если потребуется для OCR/перевода, ПК), но пользовательский сценарий должен оставаться максимально простым.

## Статус

Начальная документация. Код захвата кадра, OCR, перевода и отрисовки ещё не добавлен.
