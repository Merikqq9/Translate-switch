# Switch Translator RU

Минималистичный автоматический переводчик японского текста в русскоязычных играх для Nintendo Switch Lite (Atmosphère + Tesla).

## Целевая конфигурация

- Nintendo Switch Lite.
- Atmosphère + nx-ovlloader + Tesla Menu.
- ПК с Windows 10 для обработки изображения, OCR и перевода.
- Перевод японский → русский.

## Цель

Автоматически обнаруживать игровые реплики и показывать русский перевод непосредственно в области исходного японского текста — без отдельного окна перевода и без лишних элементов интерфейса.

## Требования к первой версии

- Автоматически обнаруживать игровые реплики на японском.
- Распознавать японский текст (OCR) и его координаты.
- Переводить только новые/изменившиеся реплики.
- Отображать перевод в координатах исходной реплики.
- Не показывать меню, статистику, историю или дополнительные панели.
- Не закрывать важные элементы игрового интерфейса.

## Важное техническое ограничение

Обычный Tesla overlay может рисовать поверх изображения игры, но сам по себе не удаляет уже отрисованные игрой японские символы. Для настоящей замены текста потребуется захват кадра, распознавание и локализация текста, маскирование исходной надписи и, где возможно, восстановление фона. На сложном фоне идеальное восстановление не гарантируется.

## Единый проект

Репозиторий и итоговый релиз будут едиными. Внутри могут быть технические модули для Switch и Windows 10, но пользователю не придётся вручную запускать и соединять несколько независимых приложений. Цель — один установочный комплект и максимально простой запуск.
